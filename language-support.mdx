Equip's default language is **English**, but many parts of the platform work in any language.

<Note>
Looking for the coding languages available in programming tests (Python, Java, and so on)? See [Programming Languages](/programming-languages) instead. This article is about human languages.
</Note>

## Language Support at a Glance

| Use case | What it covers | Language support |
|---|---|---|
| Platform | Buttons, instructions, website text, recruiter dashboard | **English** |
| Equip questions | MCQs, coding questions, and other Equip library content | **English** |
| Custom questions | Questions you create in Custom or AI Tests | **Any language** |
| Candidate responses | Answers to AI-graded or essay-type questions | **Any language** |
| Candidate emails | Invitations to assessments and AI interviews | **Any language** |

<Tip>
Most browsers, including Chrome, offer auto-translate. With auto-translate, most candidates can use the Equip platform directly even if they do not read English.
</Tip>

## Multilingual Assessments

Questions from **Equip's question library** are English only and cannot be translated. To assess candidates in another language, use **custom content**: custom quizzes, AI Tests, and AI-graded questions all accept question text in any language.

For custom quizzes, there is no dedicated multilingual-question toggle. Since you write the questions yourself, you already control the language directly. See [Multilingual Tests](/multilingual-tests) for setup details.

<Warning>
If your assessment mixes Equip library tests with custom tests, only the custom tests can appear in other languages. The library tests remain in English.
</Warning>

## Interview Languages

**Conversational AI Interviews** run in the language you choose when creating the interview, and **One-Way AI Interviews** support both a question language and a per-question response language. See [Interview Languages](/interview-languages) for the full list of supported languages and how to configure each.

<Note>
The optional **Workspace** panel in conversational interviews lets candidates answer in code or plain text, independent of the spoken interview language.
</Note>

## Candidate Language Selection

For assessments with multilingual questions enabled, candidates see a **language selector** before the test begins and pick from the languages you enabled. See [Multilingual Tests](/multilingual-tests) for the candidate's view.

<Note>
Invitation emails are fully editable, so you can write the subject and body in your candidates' language. Only the assessment link inside the email must stay intact.
</Note>
