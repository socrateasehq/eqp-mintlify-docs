Equip's default language is **English**, but many parts of the platform work in any language. This article explains what is English-only, what is fully multilingual, and how candidates pick their language.

<Note>
Looking for the coding languages available in programming tests (Python, Java, and so on)? See [Programming Languages](/programming-languages) instead. This article is about human languages.
</Note>

## Language Support at a Glance

Support for non-English languages depends on the use case:

| Use case | What it covers | Language support |
|---|---|---|
| Platform | Buttons, instructions, website text, recruiter dashboard | **English** |
| Equip questions | MCQs, coding questions, and other Equip library content | **English** |
| Custom questions | Questions you create in Custom or AI Tests | **Any language** |
| Candidate responses | Answers to AI-graded or essay-type questions | **Any language** |
| Candidate emails | Invitations to assessments and AI interviews | **Any language** |

<Tip>
Most browsers, including Chrome, offer auto-translate. With auto-translate, most candidates can use the Equip platform directly even if they do not read English.
</Tip>

## Multilingual Assessments

Questions from **Equip's question library** are available in English only and cannot be translated. To assess candidates in another language, use **custom content**: custom quizzes, AI Tests, and AI-graded questions all accept question text in any language.

For custom quizzes, you can go further with **multilingual questions**: enable multiple languages on a single test and provide question text for each language. Every candidate then attempts the same test in the language they are most comfortable with. See [Multilingual Tests](/multilingual-tests) for setup details.

Candidate answers are just as flexible. Responses to AI-graded and essay-type questions can be written in any language.

<Warning>
If your assessment mixes Equip library tests with custom tests, only the custom tests can appear in other languages. The library tests remain in English.
</Warning>

## Interview Languages

**AI Interviews** are conducted in the language you choose when creating the interview. Supported languages are:

- English (US, India, UK)
- Hindi, Kannada, Telugu, Tamil, Marathi, Bengali
- Spanish (Spain, US)
- French, German, Portuguese (Brazil), Italian

The AI interviewer asks questions and holds the conversation in the selected language. See [Interview Languages](/interview-languages) for how to configure this.

<Note>
The optional **Workspace** panel in conversational interviews lets candidates answer in code or plain text, independent of the spoken interview language.
</Note>

## Candidate Language Selection

For assessments with multilingual questions enabled, candidates see a **language selector** before the test begins.

<Steps>
  <Step title="Open the assessment">
    The candidate opens their invitation link and signs in as usual. Platform screens such as instructions appear in English.
  </Step>
  <Step title="Choose a language">
    Before the multilingual test starts, the candidate picks their preferred language from the ones you enabled.
  </Step>
  <Step title="Attempt the test">
    Questions appear in the chosen language. Every language shows the same questions and points, so grading works the same regardless of the language selected.
  </Step>
</Steps>

<Note>
Invitation emails are fully editable, so you can write the subject and body in your candidates' language. Only the assessment link inside the email must stay intact.
</Note>
