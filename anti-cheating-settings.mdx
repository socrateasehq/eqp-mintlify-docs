Apart from [AI proctoring](/ai-proctoring), Equip has four **anti-cheating settings** that make it harder for candidates to share answers or use outside help. They are set per test, separately from the [proctoring settings](/proctoring-settings) panel.

## What Each Setting Does

| Setting | What It Does |
|---|---|
| **Randomize the question order** | For quizzes that show questions all at once, each candidate sees the same set of questions in a different order. To have each candidate see a *different set* of questions from your own content, build a [Question Bank Quiz](/question-bank-quiz) first. |
| **Shuffle choices within a question** | For quizzes with MCQs and MCAs, the answer choices appear in a different order for each candidate. |
| **Disable Copy & Paste** | The candidate cannot copy the question text or paste anything into the test tab. Especially useful for coding challenges. |
| **Auto-submit on Tab-switch** | If the candidate switches to a different tab more times than a limit you set, the test is submitted automatically. |

<Note>
Candidates are told which measures are active before they start.
</Note>

## Defaults for Tests with Equip's Content

If a test uses **Equip's content**, the settings are applied automatically based on the [test type](/test-types). Questions are randomized, choices are shuffled, and copy/paste is disabled wherever the setting applies, and auto-submit on tab-switch is off.

Video Response tests are the exception: none of the four settings is on.

<Warning>
You **cannot change** these defaults. They are locked to protect the shared question bank.
</Warning>

## Configure Settings on Custom Tests

If a test uses your own content, all four settings are configurable **per test**.

{/* screenshot: anti-cheating settings panel while editing a custom test */}

<Steps>
  <Step title="Open the custom test">
    Edit your assessment and open the [custom test](/custom-tests) you want to configure.
  </Step>
  <Step title="Adjust the anti-cheating options">
    Turn the settings on or off, and set the tab-switch limit for **Auto-submit on Tab-switch**. Then save the test and update the assessment.
  </Step>
</Steps>

## How These Settings Work with Proctoring

There are two tab-switch controls. **Detect Switched Tab** (a proctoring setting) records every switch as a violation in the report, while **Auto-submit on Tab-switch** goes further and ends the test once the limit is crossed.

Disabled copy/paste, **Enforce Full Screen**, and tab-switch detection together make on-device AI tools like ChatGPT impractical. Stealth overlay tools and AI on a second phone are caught by [Auxiliary Device proctoring](/ai-usage-detection).

<Note>
Every violation, whether from proctoring or tab switching, feeds into the candidate's [Trust Score](/trust-score).
</Note>
