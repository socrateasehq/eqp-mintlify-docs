You can build your own coding questions as [Custom Tests](/custom-tests). Because coding challenges are **graded automatically**, a small setup mistake can break grading for every candidate.

## Common Problems

Most reported issues trace back to one of these setup mistakes:

| Problem | What goes wrong |
|---|---|
| **Input/output mismatch** | The slightest change in how input is read or output is printed can mark every submission as incorrect |
| **Broken boilerplate** | The driver or starter code for an enabled language does not compile or does not match the expected solution format |
| **Missing edge cases** | Test cases skip boundary values, so incorrect solutions can still score full marks |
| **Unclear instructions** | Candidates used to another platform get stuck if your problem statement does not spell out the expected format |

<Warning>
An input/output bug does not fail in a way that gets noticed right away. It marks all submissions wrong, and you may only find out after candidates have completed the assessment.
</Warning>

Where possible, [use Equip's own coding content](/equip-vs-custom-content) instead. Each question has been attempted by thousands of candidates, so it is proven to work.

## Validating Test Cases

Before inviting anyone, confirm that a correct solution passes every test case in every enabled language.

<Steps>
  <Step title="Review the problem statement">
    State the input format, the output format, and any constraints explicitly.
  </Step>
  <Step title="Check the boilerplate for every language">
    Verify the driver and starter code for each enabled language, not just the one you wrote the question in. See [Writing a Boilerplate and Test Cases](/custom-programming-test-example) for a worked example.
  </Step>
  <Step title="Verify sample and real test cases">
    Work through them by hand. Confirm the expected output matches exactly, including spacing and line breaks.
  </Step>
  <Step title="Attempt the challenge in Preview">
    Add the test to an assessment and open it in [Preview](/preview-assessment). Submit a known-correct solution in each enabled language and confirm all test cases pass. Previews are free and unlimited for your whole team.
  </Step>
</Steps>

<Note>
If you [randomize coding questions](/randomize-coding-questions), validate every variant separately. Each variant must keep at least one enabled language, and the builder will block you otherwise.
</Note>

## Getting Help

Equip's support team **cannot triage custom coding questions** for you. If a custom coding question misbehaves, in almost all cases the question was not set up correctly, and the validation steps above resolve the vast majority of issues.

<Note>
If the skill you want to test would be broadly useful to other companies, Equip can create the test for you, usually free of charge. Reach out via live chat or email hello@equip.co; turnaround is around 5 business days for most skills. See [Can't Find Your Role or Skill?](/cant-find-role-or-skill) for details.
</Note>
