Every test in an assessment and every AI interview carries its own **proctoring settings**. Each starts with defaults for its type, and you can change them per test or per interview. The ATS (job openings, live interviews, offers) has no proctoring settings.

## Available Settings

Each test has 12 proctoring toggles.

| Setting | What It Does |
|---|---|
| **Detect Audio** | Records noise and audio cues in the background. |
| **Detect Face** | Captures a photo if the camera detects no faces (camera covered, or nobody in view) or multiple faces. |
| **Detect Switched Tab** | Detects when the candidate switches to a different tab or application. |
| **Switched Tab Screenshot** | Captures a screenshot of the tab the candidate switched to. Works on Chrome, Edge, Safari, and Firefox desktop browsers. |
| **Take Random Photos** | Captures a few photos of the candidate at random points throughout the test. |
| **Prevent Multiple Monitors** | Blocks candidates connected to more than one monitor from taking the test until they disconnect the extra displays. Requires a Chromium-based browser. |
| **Capture Photo Before Start Test** | Takes a photo of the candidate's face before the test starts. |
| **Show Webcam Preview** | Lets the candidate see their own webcam preview throughout the test. |
| **Enforce Full Screen** | Candidates cannot take the test without entering full-screen mode. |
| **Enforce Desktop** | Candidates can only use a desktop or laptop. |
| **Record User Session** | Records the candidate's screen and actions (mouse clicks, keyboard typing) as they attempt the test. |
| **Auxiliary Device** | Candidates must pair their phone as a second camera watching their hands, keyboard, and screen. |

<Tip>
Some measures run on every attempt regardless of these toggles, such as device fingerprinting, IP recording, and multi-session detection. See [AI Proctoring](/ai-proctoring).
</Tip>

## Defaults by Test Type

New tests start with most settings **on**. The exceptions depend on the test type.

**Auxiliary Device** is off by default for every test type.

| Test Type | Off by Default |
|---|---|
| **Quiz** (all variants) | Enforce Desktop |
| **Programming, SQL, CSS, Typing** | None (all settings on) |
| **Excel** | Record User Session |
| **Video Response** | Detect Audio, Detect Face, Take Random Photos, Capture Photo Before Start Test, Record User Session, Enforce Full Screen, Enforce Desktop |
| **Psychometric** | Detect Audio, Detect Face, Detect Switched Tab, Switched Tab Screenshot, Take Random Photos, Capture Photo Before Start Test, Enforce Full Screen, Prevent Multiple Monitors, Enforce Desktop |
| **English Communication (CEFR)** | Detect Audio |
| **AI Interview (One-way)** | Detect Audio, Enforce Desktop |
| **AI Interview (Conversational)** | Detect Audio, Detect Face, Take Random Photos, Enforce Desktop |

<Note>
A few toggles are locked, not just defaulted. Camera-related options stay locked off for custom video response tests. Psychometric tests keep tab-switch detection locked off. AI interviews have their own locks, listed under [For AI Interviews](#for-ai-interviews).
</Note>

## Changing Settings

### For Assessments

<Steps>
  <Step title="Open the assessment's Settings">
    Create the assessment first, then open its settings from your assessment dashboard.
  </Step>
  <Step title="Go to the Test Order tab">
    Find the test you want to modify and click **Edit Settings**.
  </Step>
  <Step title="Toggle the settings you need">
    Click **Save Settings**. Then click **Update**, and your changes apply to future attempts of that test.
  </Step>
</Steps>

<Frame caption="Edit Settings link for each test in the Test Order tab">
  <img src="/images/proctoring-settings-edit-settings-link.png" alt="Test Order tab with an Edit Settings link under the Proctoring column for each test" />
</Frame>

<Tip>
The panel includes **Enable All** and **Disable All** links to flip every toggle at once.
</Tip>

### For AI Interviews

<Steps>
  <Step title="Open the interview's Settings page">
    From the [**AI Interviews** dashboard](https://equip.co/recruiter/ai-interviews/dashboard/), click **Settings** on the interview. See [Interview Settings](/interview-settings) for the rest of that page.
  </Step>
  <Step title="Expand Proctoring Settings">
    On one-way interviews it sits below **Main Settings** and **Timer Settings**. On conversational interviews it is under section 5, **Proctoring**. Both start collapsed.
  </Step>
  <Step title="Toggle the settings you need">
    Turn each toggle on or off. The locks below still apply.
  </Step>
</Steps>

| Lock | Applies To |
|---|---|
| **Detect Audio** always off | Conversational interviews |
| **Detect Audio** off when the template has audio or video questions | One-way interviews |
| No **Show Webcam Preview** toggle (the interview has its own preview) | Conversational interviews |
| **Detect Switched Tab** stays on while **Switched Tab Screenshot** is on | Both |

<Note>
In the guided setup flow you pick a proctoring level instead: **None**, **Basic** (tab and app switches), **Standard** (tab switch, camera, mic, full screen) or **Enhanced** (Standard plus auxiliary device).
</Note>
