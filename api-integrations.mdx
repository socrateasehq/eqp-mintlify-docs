Equip's **REST APIs** let you run assessments and AI interviews from inside your own ATS or internal tools. You invite candidates, fetch their results and manage job openings programmatically, without working in the Equip dashboard.

## What the API Offers

| Product | You can | You cannot |
|---|---|---|
| **Assessments** | Invite candidates to an assessment | Fetch question content directly (for example, "give me 100 Python MCQs") |
| **AI interviews** | Invite candidates to an AI interview | Have candidates attempt tests or interviews outside of Equip |
| **Both** | Pull candidates' attempts and results from one test-attempts endpoint; each attempt shows the AI interview it belongs to | |
| **ATS** | Create, read and update job openings, their pipeline stages and the stage order | Create or move job applications (read-only) |
| **ATS** | Read job posts, job applications, users and ATS insights | Change job posts, applications or users |

When you invite candidates, each gets a unique link, and you choose whether Equip sends the invitation email (it does by default) and how many days the link stays valid. The email uses the stage's linked template, then the copy saved on the assessment's or interview's **Invite** tab, then the default email.

<Note>
Every API request acts as your team's **admin recruiter**. A write on a read-only endpoint returns "API key authentication is read-only for this endpoint"; any endpoint outside the allowed list returns "API key authentication is not allowed for this endpoint".
</Note>

## Costs

API access is part of the **Integrations & Webhooks** feature on the **Elite** plan, with no separate setup fee or minimum purchase.

<Note>
Credits work the same way for API-driven invitations as for dashboard invitations. See [How Credits Work](/how-credits-work) for deduction and reclaim rules.
</Note>

## Getting Access

Every team has one **API Key**. The team admin generates it on the [**Account → Developers**](https://equip.co/recruiter/account/developers/) page.

<Steps>
  <Step title="Create a team and trial Equip">
    Sign up for a recruiter account at [equip.co](https://equip.co/account/recruiter-onboarding/) with your work email. Use your free signup credits to confirm the product works for your use case.
  </Step>
  <Step title="Subscribe to Elite">
    See [How Credits Work](/how-credits-work) for how to subscribe.
  </Step>
  <Step title="Generate your API Key">
    On [**Account → Developers**](https://equip.co/recruiter/account/developers/), click **Generate API Key** and copy the key from the dialog. It is shown only once; if you lose it, click **Rotate API Key** to get a new one.
  </Step>
</Steps>

<Warning>
Treat your API Key like a password. Anyone who has it can invite candidates, read results and edit job openings on your team's behalf, spending your team's credits.
</Warning>

## Explore the APIs

A public [Postman collection](https://www.postman.com/solar-comet-241985-1/equip-api-v3/collection/6tuspon/equip-api-v3-documentation) documents the available endpoints. You can browse it freely, but every request needs your team's API Key.

For a walkthrough of wiring the pieces together, follow this [integration guide](https://gist.github.com/siddharth-soc/255c00f83c35a9a40355189346c6fb19).

<Tip>
You do not always need the full API. If you only want results pushed to you when candidates finish, [webhooks](/webhooks) are simpler.
</Tip>
