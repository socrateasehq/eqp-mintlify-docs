An **assessment** is a collection of tests that candidates attempt one by one. The **Create Assessment** builder has three tabs: Tests, Test Order, and Settings.

## Starting a New Assessment

<Steps>
  <Step title="Click Add Assessment">
    From the [Assessments Dashboard](https://equip.co/recruiter/assessments/dashboard/), click **Add Assessment** in the sidebar.
  </Step>
  <Step title="Enter the role and experience">
    Type the role, for example "Python Developer," select the **Years of Experience**, and click Continue. Equip suggests tests and skills at a [difficulty level](/question-difficulty-levels) matched to the experience. Adjust, add, or remove tests before saving.
  </Step>
</Steps>

## Step 1: Add Tests

On the **Tests** tab, pick a test type on the left, then add one or more tests of that type.

{/* screenshot: Tests tab of the Create Assessment builder with test types listed on the left */}

<Frame caption="The Tests tab, with test types on the left and the tests of the selected type on the right">
  <img src="/images/create-assessment/tests-tab.png" width="1000" alt="Tests tab of the assessment builder for a Full Stack Developer role, with test types such as Quizzes, Programming, Communication (CEFR), Psychometric, Video Response, Typing Test, SQL, Excel and CSS listed on the left, and a quiz covering Cloud Computing, Docker and Git on the right" />
</Frame>

Test types include Quiz, Programming, English Communication (CEFR), Psychometric, Video Response, Typing Test, SQL, Excel, and CSS. See [Test Types](/test-types) for what each one measures.

Every test type can use **Equip Content**, pre-built tests from Equip's library, or **My Content**, custom tests you or your teammates created. You can mix both in one assessment.

For quizzes, use **Add Skill** to test up to 6 skills inside a single quiz, or Add Quiz to add another quiz as a separate test. See [Testing Multiple Skills](/testing-multiple-skills) for when to use which.

<Note>
The builder will not let you proceed with an empty assessment, an Equip quiz or Excel test with no questions, or a programming test with no language enabled. An Equip quiz holds at most 25 questions in total.
</Note>

## Step 2: Order Tests and Set Weightage

{/* screenshot: Test Order tab showing drag handles, weightage inputs, and estimated duration */}

<Frame caption="The Test Order tab, with a drag handle and a weightage for each test and the estimated duration above">
  <img src="/images/create-assessment/test-order-tab.png" width="944" alt="Test Order tab listing a Quiz and a Programming test, each with a drag handle, a weightage of 50, and proctoring options, under an estimated duration of 1 hr 9 mins" />
</Frame>

<Steps>
  <Step title="Arrange the tests">
    On the **Test Order** tab, drag tests into the order you want candidates to attempt them. Equip computes the Estimated Assessment Duration from the timers on every question and test.
  </Step>
  <Step title="Set weightage per test">
    Assign each test a **weightage**. Weightage is split equally by default, and the weightages must add up to exactly 100. See [Test Scores and Overall Score](/test-scores-and-overall-score) for a worked example.
  </Step>
</Steps>

<Warning>
A weighted test left at weightage 0 does not contribute to the Overall Score. Psychometric and Typing tests are always weightless by design and are excluded from the Overall Score.
</Warning>

Two more things live on this tab:

- **Proctoring settings** are configured per test here, not in the Settings tab. See [Proctoring Settings](/proctoring-settings).
- The **Randomize** icon on coding tests lets you attach a pool of Programming or SQL questions so each candidate receives one at random. See [Randomize Coding Questions](/randomize-coding-questions).

## Step 3: Configure Settings

On the **Settings** tab, the Assessment Title is required and is shown to candidates.

{/* screenshot: Settings tab with Title, Timer, and Gather Additional Details sections */}

<Frame caption="The Settings tab, with the assessment title, the start window and Gather Additional Details">
  <img src="/images/create-assessment/settings-tab.png" width="564" alt="Settings tab showing the Title field set to Full Stack Developer, Cannot Start Before and Cannot Start After date and time fields, and Gather Additional Details set to No" />
</Frame>

| Section | What you configure |
|---|---|
| **Timer** | An optional [start window](/assessment-settings#start-window): Cannot Start Before and Cannot Start After. |
| **Gather Additional Details** | Extra fields collected before the first test, such as Phone Number or LinkedIn URL. |
| **Miscellaneous** | Write results to Google Sheets, custom instructions, completion-notification emails, and a redirect URL after completion. |

Save, then start [inviting candidates](/email-invitations).
