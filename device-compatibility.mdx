## Mobile-Friendly Test Types

| Test Type | Works on Mobile? |
|---|---|
| Quiz (MCQs, essay-type questions) | Yes |
| Psychometric Test | Yes |
| English Communication (CEFR) | Yes |
| Video Response | Yes |
| Programming Challenge | No |
| SQL Challenge | No |
| CSS Challenge | No |
| Excel Test | No |
| Typing Test | No |

<Note>
Recruiters can require a computer for any test by turning on **Enforce Desktop** in [Proctoring Settings](/proctoring-settings). The test then will not load on phones or tablets.
</Note>

## Desktop-Only Test Types

Programming, SQL, CSS, Excel, and Typing tests carry a **Desktop Only** badge, and Enforce Desktop is on by default for them.

## AI Interviews on Mobile

**Conversational AI interviews** work on phones. See [Taking an AI Interview](/taking-an-ai-interview) for the full flow.

<Note>
**Enforce Desktop** applies to interviews too. Chromebooks count as computers.
</Note>

## Supported Browsers

**Google Chrome** is the recommended browser for all Equip assessments and AI interviews. Before the session starts, the instructions page checks the browser whenever the session records camera or mic, which is always the case for conversational AI interviews.

| Device | Supported browsers (minimum version) |
|---|---|
| Windows | Chrome 82, Firefox 78, Edge 88 |
| macOS | Safari 14.1, Chrome 82, Firefox 78 |
| Linux, Chrome OS, Android | Chrome 82 |
| iPhone or iPad | Safari 14.1, or Chrome 82 on iOS 16.1 or later |
| Brave, on any device | Blocked |
| Links opened inside another app (Instagram, LinkedIn, WeChat and similar) | Blocked, because in-app browsers cannot use the camera and mic |

A browser that fails is blocked, and the candidate must update it or open the link in Google Chrome.

<Note>
Sessions that record no camera or mic, such as text-only questions with no media proctoring, skip the check, so older devices can still take them.
</Note>

Some proctoring features also depend on the browser:

| Feature | Browser Support |
|---|---|
| Switched Tab Screenshot | Chrome, Edge, Safari, and Firefox on desktop |
| Multiple-monitor detection | Chromium-based browsers only (Chrome, Edge) |

<Tip>
Candidates can verify their device with the free [**demo tests**](/demo-tests) shown before the assessment. A working demo means the real test will load too.
</Tip>

## Troubleshooting Device Issues

If a test will not load or the camera and mic are not detected, try these in order.

<Steps>
  <Step title="Check the webcam and microphone">
    Confirm the camera and mic work in other apps, and that the browser has permission to use them.
  </Step>
  <Step title="Try an incognito or private window">
    This rules out extensions and cached settings that block camera or screen access.
  </Step>
  <Step title="Switch browsers">
    Try Chrome first. If Chrome is unavailable, try Safari or Edge, and use Firefox only as a last resort.
  </Step>
  <Step title="Switch devices">
    Open the same assessment or interview link on a different computer. An unfinished attempt [resumes on the new device](/resume-your-attempt).
  </Step>
</Steps>

<Note>
A candidate who has not yet seen any questions can safely click their assessment link again on any device. For issues that appear after questions have loaded, see [Candidate Issues](/candidate-issues).
</Note>
