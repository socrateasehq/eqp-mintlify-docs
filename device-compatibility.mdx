## Mobile-Friendly Test Types

| Test Type | Works on Mobile? |
|---|---|
| Quiz (MCQs, essay-type questions) | Yes |
| Psychometric Test | Yes |
| English Communication (CEFR) | Yes |
| Video Response | Yes |
| Programming Challenge | No |
| SQL Challenge | No |
| CSS Challenge | No |
| Excel Test | No |
| Typing Test | No |

<Note>
Recruiters can require a computer for any test by turning on **Enforce Desktop** in [Proctoring Settings](/proctoring-settings). The test then will not load on phones or tablets.
</Note>

## Desktop-Only Test Types

Programming, SQL, CSS, Excel, and Typing tests need a full-size screen and keyboard, so they can only be attempted on a desktop or laptop.

These tests carry a **Desktop Only** badge, and Enforce Desktop is on by default for them.

## Recommended Browsers

**Google Chrome** is the recommended browser for all Equip assessments and AI interviews. Some features depend on browser support:

| Feature | Browser Support |
|---|---|
| Switched Tab Screenshot | Chrome, Edge, Safari, and Firefox on desktop |
| Multiple-monitor detection | Chromium-based browsers only (Chrome, Edge) |
| Video interviews on iPhone or iPad | Safari required |

<Tip>
Candidates can verify their device with the free [**demo tests**](/demo-tests) shown before the assessment. A working demo means the real test will load too.
</Tip>

## Troubleshooting Device Issues

If a test will not load or the camera and microphone are not detected, work through these steps in order.

<Steps>
  <Step title="Check the webcam and microphone">
    Confirm the camera and mic work in other apps, and that the browser has permission to use them. Equip's setup screen includes test buttons for both.
  </Step>
  <Step title="Try an incognito or private window">
    This rules out extensions and cached settings that block camera or screen access.
  </Step>
  <Step title="Switch browsers">
    Try Chrome first. If Chrome is unavailable, try Safari or Edge, and use Firefox only as a last resort.
  </Step>
  <Step title="Switch devices">
    Open the same assessment link on a different computer. An unfinished attempt [resumes on the new device](/resume-your-attempt).
  </Step>
</Steps>

<Note>
A candidate who has not yet seen any questions can safely click their assessment link again on any device. For issues that appear after questions have loaded, see [Candidate Issues](/candidate-issues).
</Note>
