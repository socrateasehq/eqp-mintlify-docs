<Tip>
Quizzes, psychometric tests, English communication tests, and video responses all work on phones. Programming, SQL, CSS, Excel, and typing tests need a desktop or laptop. Whatever the device, **Google Chrome** is the recommended browser.
</Tip>

## Mobile-Friendly Test Types

Equip supports many **test types**, and several of them work well on a phone or tablet. The table below shows which tests candidates can attempt on mobile.

| Test Type | Works on Mobile? |
|---|---|
| Quiz (MCQs, essay-type questions) | Yes |
| Psychometric Test | Yes |
| English Communication (CEFR) | Yes |
| Video Response | Yes |
| Programming Challenge | No |
| SQL Challenge | No |
| CSS Challenge | No |
| Excel Test | No |
| Typing Test | No |

<Note>
Even when a test works on mobile, recruiters can require a computer for any test by turning on the **Enforce Desktop** proctoring setting. If it is enabled, the test will not load on phones or tablets.
</Note>

## Desktop-Only Test Types

**Programming**, **SQL**, **CSS**, **Excel**, and **Typing** tests run in interactive environments, such as a code editor or a simulated spreadsheet, that need a full-size screen and keyboard. These tests can only be attempted on a desktop or laptop.

Desktop-only tests are flagged with a **Desktop Only** badge, so candidates know up front which device to use. Browser recommendations are also shown before the test starts.

<!-- screenshot: assessment test list showing the Desktop Only badge on a Programming test -->

<Warning>
If your assessment includes even one desktop-only test, ask candidates to attempt the entire assessment on a computer. Switching devices mid-way is possible, but starting on the right device avoids interruptions.
</Warning>

## Recommended Browsers

**Google Chrome** is the recommended browser for all Equip assessments and AI interviews. Some proctoring features depend on browser support, so the browser a candidate picks can matter.

| Feature | Browser Support |
|---|---|
| Assessments and proctoring in general | Chrome recommended |
| Switched Tab Screenshot | Chrome, Edge, Safari, and Firefox on desktop |
| Multiple-monitor detection | Chromium-based browsers only (Chrome, Edge) |
| Video interviews on iPhone or iPad | Safari required |

Before any test begins, Equip walks candidates through camera and microphone setup with browser-specific permission guides and built-in mic and camera test buttons.

<Tip>
Candidates can verify their device works by attempting the free **demo tests** shown before the assessment. The demo checks the exact test types in the assessment, so a working demo means the real test will load too. See [Demo Tests](/demo-tests).
</Tip>

## Troubleshooting Device Issues

If a test will not load or the camera and microphone are not detected, work through this ladder in order. Most pre-start issues are resolved on the device itself.

<Steps>
  <Step title="Check the webcam and microphone">
    Confirm the camera and mic work in other apps, and that the browser has permission to use them. Equip's setup screen includes test buttons for both.
  </Step>
  <Step title="Try an incognito or private window">
    Extensions and cached settings can block camera or screen access. An incognito window rules them out.
  </Step>
  <Step title="Switch browsers">
    Try Chrome first. If Chrome is unavailable, try Safari or Edge, and use Firefox only as a last resort.
  </Step>
  <Step title="Switch devices">
    If nothing works, open the same assessment link on a different computer. Unfinished attempts resume where they left off, with the remaining time intact.
  </Step>
</Steps>

<Note>
A candidate who has not yet seen any questions can safely click their assessment link again on any device. For issues that appear after questions have loaded, see [Troubleshooting Candidate Issues](/candidate-issues).
</Note>
