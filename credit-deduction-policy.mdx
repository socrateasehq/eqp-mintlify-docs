<Tip>
An **assessment** costs 1 credit per test, per candidate: the first on invite, the rest as the candidate starts each test. An **AI interview** costs its full per-candidate price on invite. The **ATS** is free; only Bulk CV Import uses credits. Invitation credits for a candidate who never starts can be reclaimed.
</Tip>

## When Credits Are Deducted for Assessments

An Equip assessment is made up of [one or more **tests**](/assessment-hierarchy). For example, an assessment with 1 Quiz and 1 Programming Test contains 2 tests, so each candidate who completes it costs 2 credits.

To check how many tests an assessment contains:

<Steps>
  <Step title="Open the assessment's Settings">
    Click the **Settings** link on the assessment.
  </Step>
  <Step title="Visit the Test Order tab">
    The number of tests listed is the number of credits each candidate can consume.
  </Step>
</Steps>

{/* screenshot: assessment Settings page, Test Order tab showing the list of tests */}

Credits are deducted at these moments:

| Event | Credits deducted |
|---|---|
| You invite a candidate to the assessment | 1st credit, immediately on send |
| Candidate starts Test #2 | 2nd credit |
| Candidate starts Test #3 | 3rd credit, and so on |

A test counts as **started** when its questions load for the candidate. The invitation credit is deducted even if the email bounces or is never opened.

<Note>
If the candidate never starts Test #1, you can [reclaim the invitation credit](/reclaim-credits) once 24 hours have passed.
</Note>

### A Worked Example

Say you invite 10 candidates to a 2-test assessment:

| Candidate group | Credits used |
|---|---|
| 2 candidates never start | 2 (invitation credits, reclaimable) |
| 3 candidates finish only Test 1 | 3 (invitation credits only) |
| 5 candidates finish both tests | 10 (5 invitations + 5 Test #2 starts) |
| **Total** | **15 charged, 2 reclaimable** |

### Duplicate Invitations

If you try to invite the same candidate to the same assessment twice, Equip warns you first. If you proceed, 2 credits are deducted in total, and the unused invitation's credit becomes reclaimable 24 hours after it was sent.

<Note>
Credits are deducted on invite rather than on start to stop spam invitations.
</Note>

<Note>
You cannot merge tests to reduce the per-test cost, because each test type caps its questions. See [Question Limits](/question-limits).
</Note>

## When Credits Are Deducted for AI Interviews

An AI interview has no per-test staging. The candidate's full cost is deducted in one go:

| Event | Credits deducted |
|---|---|
| You invite a candidate | Full cost, on send: One-way 1 (up to 20 questions) or 2 (21 to 40); Conversational Quick 2, Comprehensive 3 |
| A candidate opens a shared link and starts | Full cost, at start |
| An invited candidate starts | Nothing more |

Sending is refused with **Insufficient credits** unless your balance covers every invite. Once the candidate starts, the invitation credits can no longer be reclaimed; before that, you can [reclaim them](/reclaim-credits) 24 hours after the invitation was sent.

## When Credits Are Deducted in the ATS

The ATS itself is free. Only one action uses credits:

| Action | Credits |
|---|---|
| [Bulk CV Import](/bulk-cv-import) | 0.01 per CV, charged for the whole batch (up to 100 CVs). The import does not start if your balance cannot cover it. |
| Live Interview and Custom stage invitations | None |

For the full cost breakdown and what happens if your balance goes negative, see [How Credits Work](/how-credits-work).
