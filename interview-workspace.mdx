## Enabling the Workspace

The **Workspace** is a per-interview setting for **conversational interviews**. It is off by default.

<Steps>
  <Step title="Open the interview's settings">
    From the [AI Interviews dashboard](https://equip.co/recruiter/ai-interviews/dashboard/), open your conversational interview's **Settings** page.
  </Step>
  <Step title="Turn on Enable Workspace">
    Switch on **Enable Workspace**. This adds a Workspace panel to the candidate's interview screen where they can write answers in code or plain text.
  </Step>
  <Step title="Set the answer format per item">
    Every question, topic, and scenario now has an **Answer format** selector.
  </Step>
</Steps>

## Answer Modes

| Answer format | What happens |
|---|---|
| **Spoken** (default) | The candidate answers out loud, as in a normal conversational interview. |
| **Written** | The AI asks the candidate to write the answer in the Workspace. |
| **Either** | The candidate chooses whether to speak or write. |

Use **Written** where you want to see exact output, such as a code exercise.

<Note>
Workspace answers are limited to **5,000 characters** per item. Candidates see an error if they exceed this.
</Note>

## Coding Answers

The Workspace has two tabs on the candidate side: a **code editor** for programming answers and a **plain text** area for prose answers and notes.

In the code editor, candidates pick from these language options:

- Python, JavaScript, TypeScript, Java
- Go, C++, C#, Ruby, Rust
- SQL
- **Any (candidate chooses)**

## Workspace Answers in Reports

Final code, written answers, and timestamped code snapshots all appear in the candidate's [interview report](/interview-reports). Snapshots are **seekable against the interview recording**: click one to jump to that moment.

<Note>
For dedicated coding evaluation at scale, Equip also offers [custom programming tests](/custom-programming-test) as part of Assessments.
</Note>
