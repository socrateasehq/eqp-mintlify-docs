---
title: "Multilingual Tests"
description: "Offer questions in multiple languages and let candidates choose the one they are most comfortable with."
---

Equip lets you run the same test in more than one language. You write each question once per language, and every candidate answers the same questions with the same scoring, just in the language they chose.

## Enabling Multiple Languages

**Multilingual questions** are a feature of tests you author yourself, such as custom tests and AI-graded tests. Equip's own question library is **English only**, so build the test with your own content to assess candidates in another language.

[Language Support](/language-support) lists what else works in any language, such as emails to candidates.

<Note>
AI Interviews handle languages separately: you choose the language when creating the interview. See [Interview Languages](/interview-languages).
</Note>

## Per-Language Question Text

When a test has multiple languages enabled, each question carries **per-language question text**. You provide a version for every enabled language instead of relying on machine translation.

<Steps>
  <Step title="Open your test in the builder">
    Go to the settings of any custom or AI-graded test.
  </Step>
  <Step title="Enable additional languages">
    Go to **Alternative Languages**, turn on **Enable Multilingual Questions**, and select the languages you want to offer.
  </Step>
  <Step title="Add question text for each language">
    Fill in every question in each enabled language, then save the test. Keep the difficulty identical across languages, or scores stop being comparable between language groups.
  </Step>
</Steps>

## The Candidate's Language Choice

Before the test begins, candidates pick from a **language selector** listing every language you enabled. They can respond in any language, in typed answers as well as audio and video responses in AI-graded tests.

{/* screenshot: candidate-facing language selector shown before the test starts */}

<Note>
The **English Communication (CEFR)** test is always delivered in English, regardless of other language settings. See [Communication Test](/communication-test).
</Note>

<Warning>
The platform interface around the questions, such as navigation and instruction screens, stays in English. Candidates who need help with it can use their browser's auto-translate feature, like the one in Google Chrome.
</Warning>
