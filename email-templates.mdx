Equip includes **email templates** for every message your pipeline sends: invitations, interview briefs, and rejections. Default templates are provided for each type, and you can edit them or create your own with dynamic variables that fill in per candidate.

## Template Types

Each of the five template types maps to a moment in your [candidate pipeline](/candidate-pipeline):

| Template Type | When It Is Used |
|---|---|
| **Assessment/AI Interview Invitation** | Inviting a candidate to an Assessment, One-Way AI Interview, or Conversational AI Interview stage |
| **Live Interview Invitation** | Inviting a candidate to a Live Interview stage, with the time and place of the interview |
| **Live Interview Panel Brief** | Briefing the interview panel when a live interview is scheduled |
| **Custom Stage Invitation** | Inviting a candidate to a Custom stage |
| **Rejection Email** | Optionally notifying a candidate when you reject them from any non-terminal stage except Offered |

Manage templates in the [**Templates**](https://equip.co/recruiter/account/templates/) section of your account, and attach one to each stage in the pipeline builder.

## Template Variables

Variables are placeholders that Equip replaces with real values when the email is sent. Each one is **click-to-copy** in the template editor.

These variables work in every template type:

| Variable | Fills In |
|---|---|
| `candidate_name` | Candidate Full Name |
| `candidate_first_name` | Candidate First Name |
| `job_title` | Job Title |
| `company_name` | Company Name |
| `sender_name` | Sender Name |
| `job_post_url` | Job Post URL |

{/* screenshot: template editor with the click-to-copy variables panel */}

### Invitation variables

Assessment and AI Interview invitation templates add variables for the link and its timing rules:

| Variable | Fills In |
|---|---|
| `test_link` | Assessment or AI Interview Link |
| `stage_type` | Assessment or AI Interview |
| `cannot_start_before_time_in_your_timezone` | Earliest Start Time (Your Timezone) |
| `cannot_start_before_time_in_utc` | Earliest Start Time (UTC) |
| `cannot_start_after_time_in_your_timezone` | Latest Start Time (Your Timezone) |
| `cannot_start_after_time_in_utc` | Latest Start Time (UTC) |
| `link_expiry_in_days` | Link Expiry (Days) |

Live Interview and Custom Stage invitation templates add a `stage_type` variable that fills in the **Stage Type**.

### Live interview variables

The Live Interview Invitation and Live Interview Panel Brief templates add variables for the booked interview:

| Variable | Fills In |
|---|---|
| `interview_date_time` | Interview Date & Time |
| `interview_date_time_utc` | Interview Date & Time (UTC) |
| `interview_duration` | Interview Duration |
| `interview_mode` | Interview Mode |
| `interview_where` | Meeting Link, Phone or Address |
| `interview_reception_note` | Ask For at Reception |
| `interview_panel_names` | Panel Members |
| `interview_hybrid_link` | Video Link for Remote Panellists |
| `interview_page_link` | Interview Page Link (panel brief only) |

Two more variables, `add_to_google_calendar_link` and `add_to_outlook_calendar_link`, let the recipient add the interview to their calendar.

<Note>
The offer email is not a template type. It is written on the offer packet, alongside the documents the candidate signs. See [Offer Documents and Packets](/offer-documents-and-packets).
</Note>

<Tip>
Include the timezone-aware start-window variables in invitation emails so candidates see the deadline in their own timezone.
</Tip>

## Stage-Transition Emails

Moving a candidate to a stage that sends email opens a dialog with a preview of the message, built from that stage's template, and you decide whether it goes out. [Stage Automation](/stage-automation) rules can also send templates.

In the dialog, you can set a **Reply-To** team member or use Schedule Send to delay delivery. For rejections, the **Send rejection email to candidates** checkbox is off by default, so nothing is sent unless you tick it. See [Changing Stages](/changing-stages) for the full flow.

{/* screenshot: stage-change invitation dialog with email preview and schedule send */}

<Warning>
Candidates with an **unverified email address** do not receive stage-change emails. The invite dialog warns you, and you can copy a verification link from the candidate's profile to share with them.
</Warning>
