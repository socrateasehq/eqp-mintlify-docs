A **Custom Test** is a test you create with your own questions, then add to any assessment. An assessment can contain only Equip's questions, only your Custom Tests, or a mix of both.

## When to Use Custom Content

Equip's library covers hundreds of skills, so start there. Build a Custom Test when the skill is missing, you want company-specific questions, you need control over timers and points, or you want to see every question and response in results.

See [Equip Content vs Custom Content](/equip-vs-custom-content) for a full comparison.

<Tip>
Missing a skill? Ask Equip via live chat or email hello@equip.co first. If the skill is broadly useful, Equip can create the test for you for free. See [Can't Find Your Role or Skill](/cant-find-role-or-skill).
</Tip>

## Supported Test Types

You can create Custom Tests of these types from the **Custom Tests** section:

| Test Type | What it is |
|---|---|
| **Quiz** | Up to 100 questions across 15 [question types](/custom-quiz-question-types), such as MCQs and essay-type |
| **Coding Challenge** | Your own [programming or SQL problem](/custom-programming-test) with test cases and starter code |
| **Question Bank** | A large pool of your questions, organized by points; not added to assessments directly |
| **Question Bank Quiz** | A quiz that draws a random set of questions from one or more [Question Banks](/question-bank-quiz) |
| **Video Response** | Up to 4 questions candidates answer by [recording a video](/video-response-questions); graded manually |

## Creating Your First Custom Test

<Steps>
  <Step title="Open the Custom Tests section">
    From the [Assessments Dashboard](https://equip.co/recruiter/assessments/dashboard/), click the [**Custom Tests**](https://equip.co/recruiter/assessments/cms/home/) link in the sidebar.
    {/* screenshot: Custom Tests link in the Assessments Dashboard sidebar */}
  </Step>
  <Step title="Choose a test type and create the test">
    Pick a type, such as Quiz or Coding Challenge, add your questions, and save.
    {/* screenshot: custom quiz builder with questions added */}
  </Step>
  <Step title="Add the test to an assessment">
    In the assessment's **Tests** tab, select the test type and click Add. Then choose **My Content** and select your Custom Test.
    {/* screenshot: Add > My Content picker in the Tests tab */}
  </Step>
</Steps>

<Tip>
For custom quizzes, you can [import questions from Excel](/import-questions-from-excel) instead of typing them one by one.
</Tip>

## Viewing Custom Quiz Results

A candidate's result for a **Custom Quiz** shows each question, the candidate's answer, and the points scored.

To download the responses of all candidates for a quiz:

<Steps>
  <Step title="Open Custom Tests">
    Click [**Custom Tests**](https://equip.co/recruiter/assessments/cms/home/) in the sidebar.
  </Step>
  <Step title="Open the results dashboard and download">
    Click the **Analytics** icon next to the quiz. Then click **Excel Download**.
    {/* screenshot: Analytics icon next to a custom quiz in the Custom Tests list */}
  </Step>
</Steps>

<Warning>
The export contains all responses for that quiz across every assessment it is used in. Either use one quiz per assessment, or filter the exported file by assessment.
</Warning>

## FAQs

**Can I add the same Custom Test to multiple assessments?**
Yes. A Custom Test is reusable across any number of assessments.

**Can I share a Custom Test directly with candidates?**
No. A Custom Test must be added to an assessment, and candidates must be invited to that assessment.

**Will my teammates see the tests I create?**
Yes. Like assessments, every Custom Test belongs to your entire team. Teammates can view, edit, and remove it.

<Note>
Writing your own coding challenge? Equip generally recommends its library questions instead, since small setup mistakes in test cases can mark every submission incorrect. See [Custom Coding Challenge Issues](/custom-coding-challenge-issues).
</Note>
