Every member of your organization has one **organization role**: Owner, Admin or Recruiter, and each uses one seat. [Departments](/departments) add a Department admin role, while the [hiring team](/job-requisitions) and [interview panel](/interview-panels) members work with you without a seat or a role.

## Change a Member's Role

<Steps>
  <Step title="Open People">
    Go to [**Account > Organization > People**](https://equip.co/recruiter/account/organization/people/).
  </Step>
  <Step title="Open the member's actions menu">
    Click the **three dots** on the member's row and choose **Make Admin**, **Remove Admin Rights** or, if you are the Owner, **Transfer Ownership**.
  </Step>
</Steps>

<Note>
When the Owner transfers ownership, they become an Admin. An organization always has exactly one Owner.
</Note>

## What Each Role Can Do

| Action | Recruiter | Admin | Owner |
|---|---|---|---|
| Create job openings, assessments and AI interviews, invite candidates, view results | ✓ | ✓ | ✓ |
| Edit company details and [hiring rules](/duplicate-applications) | ✓ | ✓ | ✓ |
| Invite and remove members, make or remove Admins | | ✓ | ✓ |
| Turn auto-join on or off | | ✓ | ✓ |
| Create departments and manage their members | | ✓ | ✓ |
| Manage [Integrations](https://equip.co/recruiter/account/integrations/) and the [Developers](https://equip.co/recruiter/account/developers/) page | | ✓ | ✓ |
| See every department's job openings and candidates | | ✓ | ✓ |
| Change the plan, buy or remove seats, edit the GSTIN | | | ✓ |
| Transfer ownership | | | ✓ |

<Warning>
No one can remove the Owner, and no one can remove themselves. To have the current Owner leave, they first transfer ownership to someone else.
</Warning>

## Reporting Lines

Reporting lines are separate from roles. Any member can record who manages whom from the same actions menu on the People tab:

| Option | What it records |
|---|---|
| **Set as my manager** | That member manages you |
| **Set as my reportee** | That member reports to you |
