Proctoring Settings: What they are, How to change them

tl;dr: When you create an Assessment, it gets created with default proctoring settings. To disable some aspects (like Camera tracking), you can visit the Test Order tab in the assessment settings


Modifying Proctoring Settings


To modify settings:


  1. Create the assessment first. It will be created with default proctoring settings
  2. Open the assessment's Settings from your Assessment Dashboard
  3. Navigate to the Test Order tab, and click on Edit Settings for the test you want to modify
  4. Toggle any proctoring setting, and Click Save Settings
  5. Click the Update button


What do the Proctoring Settings Mean?


  1. Detect Audio: Record noise and audio cues in the background.
  2. Detect Face: Capture a photo if the camera detects no faces (no face in the camera view or candidate covers the camera) or multiple faces.
  3. Detect Switched Tab: When a user switches to a different tab/application, we detect this.
  4. Switched Tab Screenshot: When a user switches to a different tab/application, capture a screenshot (Works on Chrome, Edge, Safari, and Firefox browsers for Desktop).
  5. Take Random Photos: Capture a few photos of the candidate throughout the test.
  6. Detect Multiple Monitors: Detect if the candidate is connected to more than one monitor.
  7. Capture Photo Before Start Test: Take a photo of the candidate's face before every test starts. For the first test, it is enabled by default.
  8. Enforce Full Screen: Candidates cannot take the test without entering full-screen mode when this is enabled. Recommended to avoid tab switching and cheating.
  9. Enforce Desktop: Candidates can use only desktop to take the test. Useful if you are conducting coding challenges which requires the user to have a large screen to work with.
  10. Record User Session: Records the candidate's screens and actions (mouse clicks, keyboard typing), as they attempt the test.
  11. Auxiliary Device: Candidate will have to pair their phone to their computer to take the test.
