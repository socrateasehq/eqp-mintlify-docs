How can a candidate resume their attempt?

tl;dr: The candidate should click the assessment link you shared with them (even on a different device). We automatically resume the test if possible. If it isn't, you should delete their attempt and invite them again.


Resuming an assessment


On Equip, an assessment is a set of tests that the candidate attempts one after another. As we discuss in this article, you cannot set the time limit for an entire assessment—the time limits depend on the test the candidate is on, or the particular question within a test they are on. That is, the time limit, depends on the test type.


By resume an assessment, we mean that the assessment is opened again by the candidate. This can happen because the candidate:
(i) refreshes the page
(ii) opens the assessment link on a different tab
(iii) opens the assessment link on a different browser or device.


It doesn't matter if the assessment is still "running" on a tab, or the tab has been closed. On Equip, all these scenarios are called resuming the assessment.


If a candidate has already finished the assessment, they cannot resume. They must attempt the assessment again.


Two Scenarios in resuming the assessment


When a candidate resumes an assessment, Equip tries to resume the test they were on. Some tests have a time limit set at the test level. Others have a time limit set at the question level. In the table below, only One-by-one Quiz and Video Response have time set at the question level.


Resumption Type 1: Imagine a candidate was on Question 3 in a One-by-one Quiz. If the candidate refreshes the page, they cannot answer Question 3 anymore. They will have to Skip answering it, and will have to move to Question 4. They can do this any number of times. Because the candidate hasn't seen Question 4, we don't need to check for time limits and number of resumptions to let the candidate resume the test.


Resumption Type 2: Imagine the candidate started a Programming Test at 11 AM. The test is for 45 minutes. They closed the tab at 11.20 AM and then resumed the test at 11.30 AM. They will now have 15 minutes left, because the test was supposed to end at 11.45 AM. If they try resuming the test at 11.50 AM, they won't be able to resume it.

Deleting a candidate's assessment attempt


A candidate can attempt an assessment only once. A candidate is uniquely identified by their email ID. Say an email ID, say abc@gmail.com, starts an assessment. If they click the assessment link from any other browser, etc they will resume the assessment from where they left off. If they have already finished the assessment and open the same link again, Equip will tell them that the assessment has been finished.


If you want to reset a candidate's assessment attempt so they start from the start, you must delete the assessment attempt. You can delete the attempt irrespective of whether they have finished the assessment or not. To delete the attempt, visit the page where all candidates' results are shown. You will find a few action buttons on the right of your screen. Click on the red delete icon to delete the attempt.



If you delete an attempt and the candidate attempts it again, you will be charged 2 credits for the assessment, not 1. Every time a candidate starts a test in an assessment, one credit is deducted.
