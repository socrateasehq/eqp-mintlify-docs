Every assessment has a **Settings** tab where you define how candidates interact with it: when they can start, how they log in, what details they must provide, and what happens after they finish. You can edit these settings anytime from your Recruiter Dashboard, even after inviting candidates.

{/* screenshot: Settings tab of the Assessment Settings page */}

## General Settings

| Setting | What It Does |
|---|---|
| **Assessment Title** | The name candidates see. |
| **Cannot Start Before / Cannot Start After** | Restricts when candidates can begin. See [Start Window](#start-window). |
| **Gather Additional Details** | Collects extra candidate fields. See [Candidate Details to Collect](#candidate-details-to-collect). |
| **Email Notifications** | Choose which team emails are notified on assessment creation and first candidate submission. |
| **Write results to Google Sheets** | Streams results to a spreadsheet in real time. Grant **hello@equip.co** Editor access to your sheet first. |
| **On Assessment Completion, redirect candidate** | Sends candidates to a page of your choice instead of the default completion screen. |
| **Custom Instructions** | Rich-text instructions shown before the assessment. |

Equip's default instructions already explain points, negative marking, duration, proctoring, and demo tests. Adding your own **replaces the defaults entirely**.

## Start Window

In the **Timer** section, set Cannot Start Before, Cannot Start After, or both.

<Warning>
The times you pick are in **your local time zone**. If your candidates are in other time zones, convert before you set the window, or some may find the assessment locked.
</Warning>

<Note>
The start window controls when candidates can **begin**, not when they must finish. There is no assessment-level time limit; see [Time Limits](/time-limits).
</Note>

## Candidate Details to Collect

Equip automatically captures each candidate's **first name, last name, email address, and a live photo** during login.

To collect more, set **Gather Additional Details** to Yes and choose fields under See Details:

- Phone Number
- LinkedIn URL
- Student ID
- College Name
- Graduation Year
- Department
- Work Experience (in years)

Candidates fill these in **before starting the first test**, and the values appear in your exported results.

## Per-Test Settings

Settings for individual tests live in the **Test Order** tab, not the Settings tab:

<Steps>
  <Step title="Open the Test Order tab">
    Switch from the Settings tab to Test Order.
  </Step>
  <Step title="Reorder tests and set weightage">
    Drag tests to change their order and assign a **weightage** to each. Weightages must add up to 100.
  </Step>
  <Step title="Adjust proctoring per test">
    Open each test's proctoring options. See [Proctoring Settings](/proctoring-settings).
  </Step>
  <Step title="Randomize coding questions (optional)">
    For Programming and SQL tests, click the **Randomize** icon to attach multiple questions so each candidate receives one at random.
  </Step>
</Steps>

<Warning>
If any test is left with a weightage of 0, it will not contribute to the overall score. Equip warns you about this when you save, so review weightages before inviting candidates.
</Warning>

<Note>
Time limits on Equip's own content are fixed and cannot be changed. Only **Custom Tests** let you set your own per-question or per-test timers. Psychometric and Typing Tests carry no weightage and are excluded from the overall score.
</Note>
