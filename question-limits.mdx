## Limits by Test Type

An Equip **assessment** is a set of tests, and each test contains one or more questions. Your assessment can contain any number of tests, but each individual test has a cap on questions.

| Test Type | Max Questions per Test |
|---|---|
| Quiz (Equip Content) | 25 |
| Quiz (Custom Content) | 100 |
| Programming, SQL, CSS | 1 |
| Excel | 6 |
| Typing Test | 3 |
| Video Response | 4 |
| Psychometric | Not applicable (standardized) |
| English Communication (CEFR) | Not applicable (standardized) |

**Psychometric** and **English Communication** tests are standardized, so you cannot select or add questions to them at all.

For **Programming** tests, you can pick one or more questions from Equip's library, but each question becomes its own test in the assessment. So evaluating a candidate on two coding questions means two tests, and you are charged per test. See [How Credits Work](/how-credits-work) for the deduction details.

### Need more quiz questions?

If you want more than 25 Equip Content quiz questions, split them across multiple quizzes in the same assessment.

<Steps>
  <Step title="Open your assessment's Tests tab">
    Go to the assessment settings and select the **Tests** tab.
  </Step>
  <Step title="Add a second quiz">
    Click **Add Quiz** and choose Equip's Content. For 30 questions total, put 25 in the first quiz and 5 in the second.
  </Step>
</Steps>

## Unlocking More Equip Quiz Questions

On a new account, Equip Content quizzes have an extra cap: you can add at most **4 questions per skill per difficulty level**. For example, for the Python skill you could add 4 Medium, 4 Hard, and 4 Expert questions.

To raise this cap, subscribe to any Equip plan, Standard, Premium, or Elite. This unlocks up to **10 questions per skill per difficulty level**.

| Limit | Before Unlocking | After Unlocking |
|---|---|---|
| Questions per skill per difficulty level | 4 | 10 |
| Skills per quiz | 6 | 6 |

<Note>
This cap applies only to **quiz questions from Equip's content**. There is no such restriction on other Equip test types like Programming, SQL, CSS, or Video Response, and none on questions in your own Custom Content.
</Note>

## Why These Limits Exist

The per-skill cap protects the **question bank**: anyone can self-onboard on Equip, so without a limit, someone could create an account and browse every question for a skill. See [Why You Cannot See Quiz Questions](/cannot-see-quiz-questions) for the full reasoning.

<Tip>
If the built-in limits do not fit your use case, create a **Custom Test** with your own questions. Custom quizzes support up to 100 questions, full question visibility, and configurable timers and points. See [Custom Tests](/custom-tests).
</Tip>
