Equip's **Communication Test** measures a candidate's English proficiency on the **CEFR scale**, the Common European Framework of Reference for Languages. The test is adaptive, fully auto-graded by AI, and works on both desktop and mobile.

Use it for any role where written or spoken English matters: support, sales, content, or client-facing engineering roles.

## The Four Skills

The test evaluates the four core communication skills, **Reading**, **Writing**, **Speaking**, and **Listening**, through scenario-based questions. Every question set also includes **Grammar** and **Vocabulary** questions, so the candidate's report shows six individual skill scores.

| Section | Appears in |
|---|---|
| Grammar | Every question set |
| Vocabulary | Every question set |
| Reading | Every question set |
| Writing | Every question set |
| Listening | Alternate question sets |
| Speaking | Alternate question sets |

<Note>
Add this test by choosing the **English Communication** test type in the assessment builder. It is standardized content: you cannot handpick the questions, Equip randomizes them per candidate, and each question carries its own fixed time limit.
</Note>

## How the Adaptive Test Works

Instead of giving every candidate the same fixed paper, the test adjusts its difficulty as the candidate answers. This pinpoints their level quickly, without wasting time on questions that are far too easy or far too hard for them.

<Steps>
  <Step title="Candidate self-assesses">
    Before starting, the candidate rates their own English ability. Based on this, the test begins at **A1**, **B1**, or **C1**.
  </Step>
  <Step title="Candidate answers a question set">
    Each set covers Grammar, Vocabulary, Reading, and Writing, with Listening and Speaking appearing in alternate sets.
  </Step>
  <Step title="Difficulty adjusts">
    Performance on the set decides the difficulty of the next one, as shown in the table below.
  </Step>
  <Step title="The test ends">
    The test ends once the candidate has stayed on the same level for more than 2 sets, or after a maximum of 6 sets.
  </Step>
</Steps>

| Performance on a set | Next set |
|---|---|
| Does well | One level harder |
| Answers reasonably | Same level |
| Struggles | One level easier |

<Note>
Most candidates complete the test in 4 to 6 question sets. The test never runs beyond 6 sets.
</Note>

## CEFR Levels

Results are reported on the standard CEFR scale, from **A1 (Beginner)** to **C2 (Near-Native)**. Candidates who score below the A1 threshold receive a **Below Beginner** grade.

| Level | Meaning |
|---|---|
| Below A1 | Below Beginner |
| A1 | Beginner |
| A2 | Elementary |
| B1 | Intermediate |
| B2 | Upper-Intermediate |
| C1 | Advanced |
| C2 | Near-Native |

{/* screenshot: candidate CEFR report showing overall grade and six skill scores */}

<Tip>
The overall grade is based mainly on the last two question sets: 60% from the final set and 40% from the one before it. Individual skill scores consider every set, weighted toward the most recent. See [CEFR Scores](/cefr-scores) for the full scoring breakdown and grade boundaries.
</Tip>
