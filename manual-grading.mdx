Most tests on Equip are graded automatically the moment a candidate submits. A few need human judgment, and you grade them from the assessment results page.

## Which Tests Need Manual Grading

**Manual grading** applies only where judgment is required, such as watching a video answer or comparing a design.

| Where | What you grade |
|---|---|
| Test types | Video Response (Video Interview), CSS Challenge |
| Custom quiz questions | Short Text, Single-line Input, Voice Input |

Every other test and question type is auto-graded or unscored. See [How Tests Are Graded](/grading-tests) for the full list.

<Note>
Until every test in a submission is graded, the test shows an **ungraded** label and the candidate's Overall Score also stays ungraded. Use the **Show Ungraded** filter on the results dashboard to find submissions that still need your attention.
</Note>

## Grading a Submission

The path is the same for every manually graded test.

<Steps>
  <Step title="Open the assessment results">
    Click the assessment title on your [**Assessments Dashboard**](https://equip.co/recruiter/assessments/dashboard/).
  </Step>
  <Step title="Open the test">
    Click the candidate's score for the test you want to grade.
  </Step>
  <Step title="Award points">
    Review the response, then click the **pencil icon** in the top right corner. Repeat until no questions remain ungraded.
  </Step>
</Steps>

### Video Response

Play the candidate's video before you award points. Ungraded questions have a yellow outline and are marked **Not Yet Graded**, and the **Filters** dropdown can show only those.

{/* screenshot: video response question with yellow "Not Yet Graded" outline and pencil icon */}

### CSS Challenge

Match the **Target Design** on the right against the candidate's **Code Preview** on the left, using the mobile, tablet, and desktop icons to check each breakpoint. Click **Submitted Code** to read the CSS the candidate wrote.

{/* screenshot: CSS grading view with Code Preview on the left and Target Design on the right */}

### Open-Ended Quiz Questions

Open the quiz marked ungraded, then read or listen to each answer marked **Not Yet Graded**.

## Overriding Scores

The **pencil icon** stays available on every question, so you can revise points at any time, even after a test has been fully graded. The test score and the candidate's **Overall Score** recompute automatically.

This also applies to [AI-graded responses](/ai-graded-questions): if you disagree with the AI's evaluation, edit the score and your value wins.

<Warning>
Score changes affect how candidates rank against each other. If you regrade one candidate's answer, review whether the same standard should apply to other submissions so comparisons stay fair.
</Warning>
