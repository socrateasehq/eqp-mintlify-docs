---
title: "Testing for Multiple Skills at Once"
description: "Combine multiple tests and skills in one assessment, and control how each one contributes to the overall score."
---

You can add any number of **tests** to one Equip assessment, and a single quiz can draw questions from several **skills** at once.

## Adding Multiple Tests

You can freely mix test types (Quiz, Programming, English Communication, and more) and mix **Equip Content** with your own **Custom Tests**. Candidates attempt each test one by one, and each test is completed in a single sitting.

<Steps>
  <Step title="Open the Tests tab">
    On the Create Assessment page (or Assessment Settings for an existing assessment), go to the **Tests** tab.
  </Step>
  <Step title="Add the test">
    Select a test type from the list, click its **Add** button, then choose Equip's Content, My Content, or Create New.
  </Step>
  <Step title="Configure it">
    For Equip's Content, set the skills, difficulty, and number of questions, or the equivalent for that test type. For My Content, select one of your saved tests.
  </Step>
</Steps>

<Frame>
  <img src="/images/testing-multiple-skills-adding-tests.png" alt="Tests tab with the Add Quiz options" />
</Frame>

<Tip>
Want randomized questions from your own content instead of a regular custom quiz? Use a [Question Bank Quiz](/question-bank-quiz).
</Tip>

<Note>
Two custom quizzes cannot be merged into one. If you have built them separately, add them to the assessment as two separate tests.
</Note>

## Skills Covered by a Single Quiz

If you are using Equip's quiz content, you do not need a separate quiz per skill. Click **Add Skill** at the bottom of the quiz card to add up to **6 skills** to the same quiz. Questions from the different skills are jumbled together and shown to the candidate as one quiz.

<Frame>
  <img src="/images/testing-multiple-skills-adding-skills.png" alt="Quiz card with two skills and the Add Skill button" />
</Frame>

We strongly recommend combining skills into one quiz.

| | One quiz with multiple skills | Separate quiz per skill |
|---|---|---|
| **Candidate experience** | One quiz to start and submit | A new quiz to start for every skill |
| **Results** | One combined quiz score | A separate score per quiz |
| **Credits** | 1 credit per candidate | 1 credit per candidate, per quiz |

<Tip>
For a combined **Equip Content** quiz, candidate results still include skill-wise and difficulty-wise breakdowns. For **custom quizzes**, add tags to your questions to get the same skill-wise breakdown.
</Tip>

<Note>
An Equip Content quiz is capped at 25 questions in total across all its skills. If you need more questions, or more than 6 skills, add a second quiz to the same assessment.
</Note>

## Setting Weightage

When an assessment has multiple tests, each test's **weightage** decides how much it contributes to the candidate's **Overall Score**. Equip assigns equal weightage by default.

<Steps>
  <Step title="Open the Test Order tab">
    In Assessment Settings, go to the **Test Order** tab. You can also drag tests here to change the order candidates attempt them in.
  </Step>
  <Step title="Set each test's weightage">
    Enter a weightage for every test. The values must add up to 100 before you can save.
  </Step>
</Steps>

<Frame>
  <img src="/images/testing-multiple-skills-weightage.png" alt="Test Order tab with a weightage input for each test" />
</Frame>

The Overall Score is the sum of each test's percentage multiplied by its weightage. See [Test Scores and Overall Score](/test-scores-and-overall-score) for a worked example.

<Warning>
If any test's weightage is 0, it will not contribute to the Overall Score at all, and Equip warns you about this while saving. Psychometric and Typing Tests are always weightless by design and are excluded from the Overall Score.
</Warning>

<Note>
Changing weightages later recalculates the Overall Scores of candidates who have already submitted.
</Note>
