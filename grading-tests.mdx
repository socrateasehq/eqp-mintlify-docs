<Tip>
Most tests on Equip are graded automatically the moment a candidate submits. A few question and test types, such as video responses and CSS challenges, wait for you: they show an **ungraded** label until you award points, and the candidate's overall score stays ungraded until every test is graded.
</Tip>

How a test is graded depends on its [test type](/test-types) and the question types inside it.

## Auto-Graded Tests

**Auto-graded tests** are scored by Equip as soon as the candidate submits.

| Test type | Graded automatically? |
|---|---|
| Quiz | Yes, for most question types (see below) |
| Programming Test | Yes |
| SQL Test | Yes |
| English Communication (CEFR) | Yes |
| Attention to Detail | Yes |
| Excel Test | Yes |
| Typing Test | Yes, for speed and accuracy, but excluded from the overall score |
| Psychometric | Not scored (see note below) |
| Video Response | No, graded manually |
| CSS Challenge | No, graded manually |

<Note>
**Psychometric tests** carry no points and are excluded from the overall score. Candidates get a personality graph instead; see [Psychometric Scores](/psychometric-scores).
</Note>

### Grading by quiz question type

Within a quiz, grading depends on the **question type**. Auto-graded question types include:

- **MCQ** (single correct answer)
- **MCA** (multiple correct answers)
- **Categorize**
- **Transcription**
- **Autograded Text** (exact-match expected answer)

These quiz question types are graded manually by the recruiter:

- **Voice Input**
- **Short Text** (essay-style answers)
- **Single-line Input**

<Tip>
MCQs in Equip's own quiz content always carry **negative marking**, and it cannot be turned off. For custom quizzes, it is optional. See [Negative Marking](/negative-marking).
</Tip>

## AI-Graded Answers

For **AI-graded questions**, Equip's AI evaluates the response and assigns points. This applies to open-ended text, audio, and video answers in AI-graded tests and AI interviews.

You can steer the evaluation with an optional **per-question AI evaluation prompt**, and with test-level evaluation context that applies to the whole test.

<Note>
AI scores are not final. Open any response and adjust the awarded points manually. See [AI-Graded Questions](/ai-graded-questions) for setup details.
</Note>

## Manually Graded Tests

Two test types always need a recruiter to grade them: **Video Response** tests and **CSS Challenges**. Quizzes containing Voice Input, Short Text, or Single-line Input questions also need a manual pass for those questions.

### Finding ungraded submissions

<Steps>
  <Step title="Open the assessment results">
    Tests that still need grading are labeled **ungraded**.
  </Step>
  <Step title="Filter with Show Ungraded">
    Use the **Show Ungraded** filter on the Dashboard to list every submission that still needs grading.
  </Step>
  <Step title="Grade each pending question">
    Review the candidate's response, then click the **pencil icon** to assign points.
  </Step>
</Steps>

### Editing points after grading

Wherever you see the **pencil icon**, you can change the points for a question, even if it was already graded automatically or manually.

<Note>
When you change a question's points, Equip recalculates the test score and the candidate's overall score automatically. Weightages you set in the Test Order tab still apply; see [Test Scores and Overall Score](/test-scores-and-overall-score) for how the overall score is computed.
</Note>

For step-by-step walkthroughs of grading video responses and CSS challenges, see [Manual Grading](/manual-grading).
