Instead of typing questions into a **Custom Quiz** one at a time, fill an Excel file and import them in a single upload. Imported questions are **appended**, so you can also add to a quiz that already has questions.

## Downloading the Template

<Steps>
  <Step title="Open Custom Tests">
    From your [**Assessments Dashboard**](https://equip.co/recruiter/assessments/dashboard/), select [**Custom Tests**](https://equip.co/recruiter/assessments/cms/home/). Click **New**, or open an existing quiz.
  </Step>
  <Step title="Download the template">
    Click **Import** at the top right of the quiz, then **Download Template**. Alternatively, download the [Google Sheets template](https://docs.google.com/spreadsheets/d/1_QgE_eX2Rb4mKcNtpnc8ojhi7wAQGRrys3Gte7hWcS0/edit?usp=sharing) as an Excel file.
    {/* screenshot: custom quiz editor with the Import button highlighted at top right */}
  </Step>
  <Step title="Fill in your questions">
    Add one question per row, following the column rules in the next section.
  </Step>
  <Step title="Upload the file">
    Back in your quiz, click the **Import from Excel** icon and select your file. Optionally enable **Autocalculate Negative Points** before uploading.
  </Step>
</Steps>

<Warning>
Do not remove any columns from the template. Your file must contain **only one sheet** and **no empty rows**, or the import will fail.
</Warning>

## Formatting Questions

| Column | Required | What to Enter |
|---|---|---|
| **Question Type** | Yes | `MCQ` (single correct answer) or `MCA` (multiple correct answers) |
| **Question** | Yes | The text of the question |
| **Opt1 to Opt5** | At least 2 | The answer choices. With three choices, fill Opt1 to Opt3 and leave the rest blank |
| **CorrectAnsInd** | Yes | For an MCQ, the number of the correct option (e.g. `2`). For an MCA, comma-separated numbers with no spaces (e.g. `2,3`) |
| **Markdown** | No | Enter `1` to render the question and options as Markdown |
| **Points** | No | Points awarded for a correct answer |
| **Time** | No | Time limit for the question, in seconds |
| **Image** | No | A direct image URL ending in `.jpg`, `.png`, etc. |
| **Tags** | No | One or more tags, separated by commas |

<Note>
The Excel import supports MCQ and MCA questions only. You can add other [question types](/custom-quiz-question-types) in the quiz after the import.
</Note>

### Autocalculate Negative Points

Enable **Autocalculate Negative Points** during the import to assign negative points to every MCQ automatically:

```
Negative Points = Points Assigned / Number of Options
```

For example, an MCQ worth 2 points with 4 options gets 0.5 negative points. MCAs are never auto-assigned negative points.

## Markdown and LaTeX Support

Enter `1` in the **Markdown** column to render the question text and options as Markdown. Leave it blank for plain text.

<Note>
Write mathematical equations in **LaTeX** inside your Excel file, then enable LaTeX in the quiz's **Advanced Settings** so they render for candidates.
</Note>

## Troubleshooting Imports

| Symptom | Fix |
|---|---|
| Upload rejected | Restore the original template columns, keep a single sheet, and delete blank rows |
| Wrong answers marked correct | In **CorrectAnsInd**, use a single number for MCQs; for MCAs, separate numbers with a comma and no space (`2,3`) |
| A question has too few choices | Every question needs at least **Opt1** and **Opt2** |
| Images not showing | Use a direct URL ending in `.jpg`, `.png`, etc. Google Drive links and links to pages containing an image do not work |
| Equations show as raw text | Turn on LaTeX in the quiz's **Advanced Settings** |

<Note>
Importing the same file twice creates duplicate questions. Remove the extra questions in the quiz editor.
</Note>
