**Custom report templates** replace the default interview report with a holistic evaluation you design yourself. The same templates work for both one-way and conversational interviews.

<Note>
Custom report templates are included with **annual Premium** and **Elite** plans. If you don't see **AI Interview Reports** under Templates, check your plan or [contact support](/contact-support).
</Note>

## Create a Report Template

One template can be reused across many interviews.

<Steps>
  <Step title="Open the templates page">
    Go to [**Templates**](https://equip.co/recruiter/account/templates/), under Account in the sidebar, and open [**AI Interview Reports**](https://equip.co/recruiter/account/templates/ai-interview-reports/).
  </Step>
  <Step title="Name the new template">
    Enter a **Template Name** and a short Description so teammates know when to use it.
  </Step>
  <Step title="Fill in the editor tabs">
    Complete the three required tabs: LLM Prompt, Response Schema, and Jinja Template. Use the fourth tab, **Preview**, to check the rendered result before saving.
  </Step>
</Steps>

Only **Active** templates can be attached to an interview. Archive a template to retire it from the dropdown without deleting it. Deleting a template that is currently in use archives it instead.

## Evaluation Prompts

The **LLM Prompt** tab holds the instructions the AI follows when it evaluates candidate responses. At the end of your prompt, point to `{{response_schema}}` so the AI has the schema as context when it writes its evaluation.

<Tip>
Be explicit about every field you expect the AI to fill in. If your schema has a `communication_score`, tell the prompt what a high or low communication score should mean.
</Tip>

## Output Schema

The **Response Schema** tab defines the structure of the AI's evaluation as a JSON schema, and the AI's output is constrained to match it.

Every field you define here becomes a variable you can place in the report layout. For example:

```json
{
  "type": "object",
  "properties": {
    "overall_summary": { "type": "string" },
    "communication_score": { "type": "number" }
  }
}
```

## Report Layout and Preview

The **Jinja Template** tab is where you design the report itself. Write HTML and drop in schema fields as Jinja variables, for example:

```html
<div>{{ overall_summary }}</div>
```

In the **Preview** tab, paste sample data as JSON, such as `{"communication_score": 85}`, to see how a finished report will look.

<Warning>
Keep the field names in your Jinja layout identical to the field names in your Response Schema. A variable that does not exist in the schema will never receive a value.
</Warning>

## Attach a Template to an Interview

Templates are attached per interview. For conversational interviews, pick a template from the **Report Template** dropdown in the Settings section of the interview's settings page. For one-way interviews, the template is attached under the template's own settings instead.

| | Default report | Custom template report |
|---|---|---|
| **Evaluation** | Equip's standard evaluator | Your LLM Prompt, run holistically across the interview |
| **Contents** | Recommendation, Strengths, Areas for Improvement, Summary, Topic Performance | The fields defined in your Response Schema |
| **Layout** | Fixed | Your Jinja Template |
| **Setup needed** | None | An Active template attached to the interview |

Once a template is attached, the rendered report appears in place of the default summary on the candidate's results page.

<Note>
Select **None** in the dropdown to restore the default report for future interviews.
</Note>
