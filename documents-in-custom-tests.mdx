The **Document** question type lets you upload a single reference PDF in a parent question and ask several sub-questions based on it. This is ideal for case studies: follow the document with MCQ, MCA, Short Text, or other question types.

## Attaching Documents

You add a Document question while building a [Custom Test](/custom-tests).

<Steps>
  <Step title="Create or open a custom quiz">
    From the [Assessments Dashboard](https://equip.co/recruiter/assessments/dashboard/), open [**Custom Tests**](https://equip.co/recruiter/assessments/cms/home/) and create a new quiz, or open an existing one.
  </Step>
  <Step title="Select the Document question type and upload the PDF">
    Choose **Document** from the question type drop-down menu and attach the PDF. Instructions for candidates are optional and go in the **Description Text** field.
  </Step>
  <Step title="Add sub-questions">
    Create the questions that reference the document, and set **points** for each sub-question if required.
  </Step>
</Steps>

{/* screenshot: custom quiz builder with the Document question type selected and a PDF uploaded */}

<Note>
A **time limit** can be set only on the parent Document question, not on individual sub-questions.
</Note>

### Document vs Comprehension

The **Comprehension** question type also nests sub-questions under shared reference material. The difference is the format of that material.

| Question type | Reference material | Best for |
|---|---|---|
| **Comprehension** | Long text or images entered directly in the question | Reading passages, short briefs |
| **Document** | An uploaded PDF file | Case studies, reports, multi-page material |

## How Candidates See Them

Candidates see the PDF at the top, with all sub-questions displayed at once underneath it. They can scroll through the document and answer the sub-questions in any order.

{/* screenshot: candidate view showing the PDF with sub-questions listed below it */}

<Note>
MCQ and MCA sub-questions are auto-graded, while Short Text answers need [manual grading](/manual-grading).
</Note>
