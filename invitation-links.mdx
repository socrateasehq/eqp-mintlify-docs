## Unique Links per Candidate

When you send [email invitations](/email-invitations), each candidate receives a unique **assessment or AI interview link** that only they can use. AI interview invitations go out from the same email invitations dashboard as assessment invitations.

<Steps>
  <Step title="Candidate opens the link and gets a verification code">
    Equip sends a verification code to the invited email address. See [Candidate Login Methods](/candidate-login-methods) for the sign-in flow.
  </Step>
  <Step title="Candidate verifies and starts">
    The code takes them straight to the assessment or AI interview. No password or account is needed.
  </Step>
</Steps>

{/* screenshot: candidate email verification page with the 6-digit code prompt */}

<Note>
Because the verification code always goes to the original invitee's inbox, **forwarding a link does not transfer the invitation**.
</Note>

### Switching devices

Clicking the link again on a different device resumes the attempt with the remaining time intact.

A fresh invitation therefore cannot grant a second attempt: any new link resumes the unfinished attempt. See [Candidate Re-Attempts](/candidate-reattempts) to allow a genuine retake.

## Link Expiry

By default, invitation links **never expire**. To set an expiry, enter 1 to 365 in the **Link Expiry (days)** field on the **Send Invitations** tab, and links stop working that many days after sending. The field works the same way for AI interview invitations.

{/* screenshot: Send Invitations tab with the Link Expiry (days) field highlighted */}

<Tip>
To control the exact start window instead, use the **Cannot Start Before** and **Cannot Start After** [assessment settings](/assessment-settings).
</Tip>

## Invalid and Already-Used Links

When a link stops working, the candidate sees a page that explains why. For AI interviews, an expired or invalid link shows a **Link Expired** or **Link Invalid** page asking them to contact whoever shared it.

| Situation | What the candidate sees |
|---|---|
| Link expired | An error page explaining the link is no longer valid |
| Credit reclaimed | The link no longer opens the assessment or AI interview |
| Attempt deleted by the recruiter | An error page; the candidate needs a fresh invitation |
| Assessment already completed | The completion screen, not the tests again |
| Someone else opens the link | The code still goes to the invited email, so they cannot proceed |

If a candidate says they never received or lost their link, check its [email status](/email-status) first, then re-invite. The unused link's credit is reclaimable after 24 hours as long as the candidate never started.

<Warning>
An invitation is revoked only by [reclaiming the credit](/reclaim-credits), which is destructive: it invalidates the candidate's link and deletes any test data tied to it. Only reclaim when you are sure the candidate should not, or will not, attempt the assessment.
</Warning>
